# APT Should Be Extended With Resonance

Source: iteration-3.2 of APT theory (`devdocs/inquiries/apt_modulator_landscape/finding.md`).

## What Resonance Is

**Resonance** is the 4th attachment variable added in iteration-3.2, alongside Charm, Hope, and Fear.

**Definition:** genuine mutual recognition between two parties — sharing world-models, values, frameworks, or ways of seeing. The "you get me" signal. It emerges **dyadically** when both parties' internal maps align enough for recognition to register.

## Key Structural Commitments

- **Not a modulator.** It's an attachment variable operating **additively** within f, alongside Charm/Hope/Fear.
- **Dyadic, not individual.** It's a property of the pair, not of either person alone — which is why it's a different architectural category from the modulators (g₁ SP, g₂ Coherence, g₃ EC), all of which are individual properties.
- **Can generate attachment alone** (the decisive test): the shared-niche-interest case — two strangers discover an unusual shared interest (e.g., medieval Ottoman financial instruments) and attach via recognition with Charm/Hope/Fear ≈ 0. Multiplicative modulators can't do this (× 0 = 0); therefore Resonance is additive in f.

## Updated Multiplicative Gating Formula

```
Attachment ≈ f(charm, hope, fear, resonance) × g₁(SP) × g₂(Coherence) × g₃(Emotional Composure)
```

## Distinct From Dialogue-Focus

Dialogue-Focus (a Self-Positioning species, see `self_focus_generalization/finding.md`) is one party's individual attention on shared inquiry — an individual property. Resonance is the dyadic emergent — a relational property.

When both parties are in Dialogue-Focus on the same object → Resonance emerges. But Dialogue-Focus can operate solo (one party), and Resonance can emerge in other species combinations if values align. They interact but aren't reducible to each other.

## Operational Signals (PRAGMA Detection)

- Spontaneous agreement rate (not social-obligation)
- Language convergence (both parties start using each other's terms)
- Shared-reference comfort (both can allude to the same things without explanation)
- Non-explicit mutual understanding ("you know what I mean" landing correctly)
- Co-construction patterns in Dialogic Function

**PRAGMA → Resonance mapping:** Convergent cross-dyad signals. Dialogic Function patterns showing co-construction; Information Density match; language-model convergence over conversation.

## TYPE Implication

Per iteration-3.2.1 (`attachment_variable_interactions/finding.md`), Resonance-dominant attachment classifies as **Bonded/deep** TYPE — persists through absence, maintained via shared model. This is qualitatively different from Charm-dominant (status/admiration, weakens as access recedes) or Hope-dominant (transactional, dissolves when exchange ends).
